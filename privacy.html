01

Scope and operator

Quiet Alpha Collector (“the Collector”) is a private, single-owner research-data utility. It collects public-source research records, builds validated JSON artifacts, and publishes immutable daily batches to a Google Drive folder configured by the owner. It is not a public software service, advertising platform, broker, trading system, or financial adviser.

中文摘要：Quiet Alpha Collector 是单一所有者使用的研究资料工具，用于把公开来源数据整理、校验后写入指定 Drive 文件夹；它不是公共 SaaS、广告平台、券商或自动交易系统。

02

Google user data accessed

The Collector requests the Google Drive OAuth scope https://www.googleapis.com/auth/drive. That scope is technically capable of viewing and managing all files in the authorizing account. The Collector's implemented operations are limited to:

  • listing file and folder metadata under the configured root folder and its batch folders;
  • creating dated folders and run-specific folders beneath that root;
  • uploading five named JSON batch artifacts and updating two named JSON status/pointer files;
  • downloading those files to verify SHA-256 hashes and byte counts;
  • reading the prior pointer and the source_state.json file referenced by that pointer.

The Collector does not request Google profile, Gmail, Calendar, Contacts, or advertising data. It does not delete Drive files. It does not intentionally inspect files outside the configured batch tree or files referenced by its own pointer.

中文摘要：OAuth scope 本身可查看和管理全部 Drive 文件，但程序实际只在配置的根目录、批次目录和自身 pointer 指向的文件中列举、创建、上传、回读与更新 JSON；不会删除 Drive 文件，也不申请 Gmail、日历或联系人数据。

03

How Google user data is used

Drive data is used only to publish, verify, resume, and expose the current state of the owner's research batch. Uploaded files are downloaded immediately after publication to verify integrity. The latest pointer changes only after all required artifacts match their locally calculated hashes and byte counts.

Google user data is not used for advertising, audience profiling, credit decisions, automated trading, or training generalized artificial-intelligence models.

04

Storage and security

  • The OAuth client ID, client secret, and refresh token are stored in Google Secret Manager and provided only to the Cloud Run Job at execution time.
  • Short-lived access tokens are held in runtime memory and refreshed when required.
  • Batch artifacts remain in the owner's Google Drive. Temporary working files exist only in the job's ephemeral runtime environment.
  • Operational status and error information may be written to Cloud logs and the named run-status file. The application is designed not to log OAuth secrets or Drive file contents.
  • Published artifacts are re-downloaded and verified by SHA-256 digest and byte count before the latest pointer is updated.

No security system is perfect. The operator limits access through project IAM, Secret Manager, a dedicated runtime identity, and a destination-folder identifier.

05

Sharing, sale, and Limited Use

The Collector does not sell Google user data. It does not share Google user data with advertisers, data brokers, or unrelated third parties. Google Cloud and Google Drive process data only as infrastructure providers necessary to operate the Collector. GitHub Pages hosts this public policy site but does not receive the owner's Drive content or OAuth credentials from the Collector.

Quiet Alpha Collector's use of information received from Google APIs will adhere to Google API Services User Data Policy, including the Limited Use requirements.

06

Retention and deletion

Batch files and status files remain in Google Drive until the owner deletes them. OAuth credentials remain in Secret Manager until the owner disables or destroys their secret versions, revokes the Google authorization, or deletes the Cloud project. Cloud execution logs follow the retention settings of the owner's Google Cloud project.

The owner may remove Collector data by deleting the Collector_Batches contents in Drive. Revoking OAuth access stops future Drive API access but does not automatically delete files already created in Drive.

07

Your choices and control

The authorizing owner can stop or restrict the Collector at any time by pausing its scheduler, disabling the Cloud Run Job, revoking the app under Google Account third-party access settings, disabling the stored refresh token, or deleting generated Drive data.

Because this is a personal-use application, no other person should authorize it unless the operator has explicitly approved that access.

08

This public website

This static website contains no sign-in form, advertising pixel, analytics script, or application cookie. GitHub Pages, DNS providers, certificate authorities, and network intermediaries may process ordinary request metadata such as IP address, user agent, requested URL, and timestamp under their own policies. Visiting this site does not grant the Collector access to Google Drive.

09

Policy changes and contact

This policy will be updated if the Collector's Google data practices materially change. The effective date at the top identifies the current version.

For a privacy question or deletion request, contact the operator through the public Quiet Alpha OAuth Site issue tracker. Do not include OAuth tokens, client secrets, Drive file contents, payment information, or other sensitive data in a public issue.

中文摘要：如需停止访问，可暂停 Scheduler、停用 Job、在 Google 账户中撤销授权、删除 Secret Manager 中的凭据，并自行删除 Drive 批次。公开 issue 中请勿提交任何密钥或文件内容。
